## 3. Scheduled jobs (both environments)

| Job | Schedule (UTC) | What it does |
|---|---|---|
| `check-overdue-invoices` | daily 01:00 | Marks sent/partially-paid invoices past due as **overdue**; notifies Super Admin, CEO, COO, Accountant |
| `daily-contract-checks` | daily 02:00 | Contract expiry status + notifications |
| `daily-followup-sweep` | daily 03:00 | Opens follow-ups for overdue invoices |
| `monthly-backup` | 1st of month 00:30 | Exports data backup; logged in Backups |
| `security-alert-check` | hourly | Failed-login security alerts |
